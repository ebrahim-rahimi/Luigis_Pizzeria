# Luigi's Pizzeria 🍕

A desktop GUI application built in Java to simulate a pizzeria ordering and management interface. This mini-project was created to practice Java GUI libraries, event-driven programming, and structured software planning.

## Features

* **Interactive Graphical User Interface:** Built using Java GUI libraries for browsing and ordering items.
* **Custom Assets & Media:** Includes custom visual resources located in `resources/images`.
* **Software Engineering Documentation:** Accompanied by requirements analysis (`Anforderungsanalyse.xltx`), pseudocode (`Pseudocode`), and structured test cases (`Test Cases.xltx`).

## Prerequisites

* **Java Development Kit (JDK):** JDK 11 or higher
* **IDE (Recommended):** IntelliJ IDEA (project configuration included via `Luigis_Pizzeria.iml`) or Eclipse
